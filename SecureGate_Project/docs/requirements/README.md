# Product Requirements

Requirements should be derived from:

1. Research findings
2. User needs
3. Security requirements
4. Technical constraints
5. Evaluation requirements

Each significant requirement should have an identifier.

Example:

REQ-SEC-001
> SecureGate shall support configurable severity thresholds for security-gate decisions.

Requirements should be linked to GitHub issues and, where relevant, research questions and experiments.
