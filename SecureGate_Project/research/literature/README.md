# Literature Review

Store literature-review materials here.

## Literature matrix fields

For each paper, record:

- Paper ID
- Title
- Authors
- Year
- Venue
- DOI/URL
- Problem
- Research questions
- Method
- Architecture
- Security tools
- Dataset/test environment
- Security gate
- Policy mechanism
- Evaluation metrics
- Results
- Limitations
- Research gap
- Relevance to SecureGate

## Initial target

Identify approximately 20–30 high-quality and directly relevant academic sources before freezing the research gap.

Prefer peer-reviewed and authoritative sources.
